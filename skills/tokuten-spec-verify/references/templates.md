# 仕様書ひな形（コピペ用）

## 要件定義書
```
# 【ツール名】要件定義書  v1.0

## 1. 目的
【何のために作るか】

## 2. 要件一覧
| ID | 要件 | 受入基準（どうなれば満たした？） |
|---|---|---|
| REQ-001 | 【　】 | 【　】 |
| REQ-002 | 【　】 | 【　】 |
| REQ-003 | 【　】 | 【　】 |

## 3. やらないこと
【スコープ外】
```

## 詳細設計書
```
# 【ツール名】詳細設計書  v1.0

| ID | 設計内容 | 対応する要件 |
|---|---|---|
| DSG-001 | 【画面・処理の設計】 | → REQ-001 |
| DSG-002 | 【　】 | → REQ-002 |
```

## テスト表
```
# 【ツール名】テスト仕様  v1.0

| ID | テスト内容 | 期待結果 | 確認する要件 |
|---|---|---|---|
| TST-001 | 【　】 | 【　】 | → REQ-001 |
| TST-002 | 【　】 | 【　】 | → REQ-002 |
```

## 最終チェック（全部✓で完成）
- [ ] REQ-xxx が一意（重複なし）
- [ ] すべての REQ に受入基準がある
- [ ] すべての REQ に、対応する DSG が1つ以上
- [ ] すべての DSG が、いずれかの REQ に紐づく
- [ ] すべての REQ に、確認する TST がある
