# 黒猫先生の日めくり ― プロンプト特典（kuroneko-prompt-pack）

書籍の購入者特典として収録した「実戦プロンプト80本」＋「スパルタ式プロンプト集①〜⑲」を、コピペで使える形で収めたパックです。すべて著者（YUKIKO／うさうさ研修工房）が本書のために書き溜めたものです。

## いつ使うか
- 単一HTMLの個人開発ツールを **作る・直す・磨く・お客様に渡す** とき → `references/jissen-prompts-80.md`
- 成果物を **商用・実務レベルの品質へ叩き上げる**（敵対的テスト／要件監査／図⇄実装レビュー／変更・リリース／ドキュメント）とき → `references/sparta-qa-prompts.md`
- **思考そのもの**を回す（構造を見抜く／拡散と収束／実行プラン化／伝える文章／具体化／抽象⇄具体の往復）とき → `references/sparta-thinking-prompts.md`

## 使い方（共通ルール）
1. 目的に合うセクションを下の索引から選び、該当プロンプトをコピーする。
2. 文中の **【　】 や { } を自分の状況に置きかえて** からAIに貼る。
3. 「スパルタモード」の宣言プロンプト（各集の「0. 最初に宣言」）を先に送ると、以降の出力が商用基準になる。
4. **厳しさは成果物と品質に向け、人格は責めない。**

## 守る原則（このパックの背骨）
- **嘘をつかない**：実在しない関数・API・文献・URLをでっち上げない。確証がなければ「未確認」と書く。
- **事実と推測を分ける**：推測は推測と明示する。
- **査読とpreprintを区別する**：論文を引くときは査読有無・調査時点を添える。
- **AIの出力は人が検証する**：最終判断は人が行う前提で使う。
- URL・年・媒体は収録時点（2026年6月）のもの。利用時に各サイトで再確認する。
