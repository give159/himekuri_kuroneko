# 単一HTML 実装・出荷前チェックリスト

## 実装の約束（コードに必ず入れる）
- [ ] HTML/CSS/JS が1ファイルに収まっている（外部読み込みなし）
- [ ] オフライン（ネットなし）で基本機能が動く
- [ ] 保存は localStorage。読み込みは try-catch＋既定値マージで、壊れていても起動する
- [ ] 画面出力はすべてエスケープ（`& < >` を無害化）
- [ ] APIキー等の秘密情報をソースに書いていない（設定欄で入力）
- [ ] スマホ縦画面で横スクロールが出ない
- [ ] 外部AI接続は任意。失敗時はローカル応答にフォールバック（無応答にしない）
- [ ] 外部呼び出しにタイムアウトがある（待ちすぎない）

## 出荷前テスト（実ブラウザ）
- [ ] 起動：Consoleに赤エラー0
- [ ] 主要機能が3つとも動く
- [ ] 再読み込みで保存内容が復元される（保存が必要な場合）
- [ ] `<img src=x onerror="alert(1)">` を入力してもalertが出ない
- [ ] スマホ実機で崩れない・ボタンが押せる
- [ ] 音/声がある場合：一度タップしてから鳴る（自動再生制限対応）

## 版を上げるとき
- [ ] 版表記を3箇所（画面表示・診断ログ・ファイル名）で一致
- [ ] CHANGELOGに1行追記
- [ ] 変更後、テストを1番からやり直す
