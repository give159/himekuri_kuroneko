## 6. ★重要7関数を一行ずつ

### 6-1. state ― 今の状態をまとめる
```js
let state={ mode:"静寂", params:Object.assign({},{kind:8,harsh:6,humor:7,calm:9,intel:9}), slots:{}, pts:0 };
```
- `let state={` … 変えられる入れもの「state（状態）」を作る。
- `mode:"静寂",` … 今の気分は「静寂」。
- `params:Object.assign({}, {...})` … 人格5軸。`Object.assign`（オブジェクト・アサイン）はコピーして入れる（元を壊さない）。
- `slots:{},` … プリセット保存用の空の棚。
- `pts:0` … 応援ポイント0。
- ※イメージ：アプリの「今の気分ノート」。

### 6-2. load() ― 保存を読みこむ
```js
function load(){
  try{const raw=localStorage.getItem(STORE_KEY);if(raw){const o=JSON.parse(raw);
    if(o.mode)state.mode=o.mode; if(o.params)state.params=o.params;
    if(o.slots)state.slots=o.slots; if(typeof o.pts==="number")state.pts=o.pts;}}catch(e){}
}
```
- `try{` … 失敗するかもしれない処理を安全に囲む。
- `localStorage.getItem(STORE_KEY)` … 保存箱から鍵で取り出す。
- `JSON.parse(raw)` … 文字列を元のデータに戻す。
- `if(o.mode)...` … **あるものだけ**今の状態へ反映。
- `catch(e){}` … 失敗しても何もせず通過（＝止まらない）。

### 6-3. save() ― 保存する
```js
function save(){
  try{const raw=localStorage.getItem(STORE_KEY);const o=raw?JSON.parse(raw):{};
    o.mode=state.mode;o.params=state.params;o.slots=state.slots;o.pts=state.pts;
    localStorage.setItem(STORE_KEY,JSON.stringify(o));}catch(e){}
}
```
- `raw?JSON.parse(raw):{}` … 既存があれば読み、無ければ空箱。
- `o.mode=state.mode; ...` … 今の値を保存用の箱へ写す。
- `JSON.stringify(o)` … 箱を文字列に変えて保存。

### 6-4. tick() ― 1秒ごとの時計
```js
function tick(){
  const now=new Date();
  const h=now.getHours(),m=now.getMinutes(),s=now.getSeconds();
  const p2=n=>String(n).padStart(2,"0");
  document.getElementById("clock").innerHTML=`${p2(h)}:${p2(m)}<span class="sec">:${p2(s)}</span>`;
}
```
- `new Date()` … **いまこの瞬間**の時刻。毎回読み直すのがズレない秘訣。
- `getHours/Minutes/Seconds` … 時・分・秒を取り出す。
- `p2=n=>...padStart(2,"0")` … 9→"09"のように2ケタに整える小関数。
- `getElementById("clock")` … 画面の時計の場所に数字を入れる。

### 6-5. escapeHtml() ― 危険な入力を無害化
```js
function escapeHtml(s){return s.replace(/[&<>]/g,c=>({"&":"&amp;","<":"&lt;",">":"&gt;"}[c]));}
```
- `s.replace(/[&<>]/g, ...)` … `&` `<` `>` を安全な表記に置きかえて返す。
- これが無いと、入力に紛れた命令で画面が乗っ取られる（XSS）。表示前の「安全確認」。

### 6-6. mask ― 鍵を伏せ字に
```js
const mask=k=>k?("****"+String(k).slice(-4)):"(なし)";
```
- `k?( ):"(なし)"` … 鍵があれば前、無ければ「(なし)」。
- `"****"+String(k).slice(-4)` … `****`＋末尾4文字だけ。診断ログを安全に共有できる。

### 6-7. withTimeout() ― 待ちすぎ防止
```js
function withTimeout(p,ms){ return Promise.race([p, new Promise((_,rej)=>setTimeout(()=>rej(new Error("timeout "+ms+"ms")),ms))]); }
```
- `Promise.race([p, ...])` … 2つを競争させ、先に終わった方を採用。
- 後半は「`ms`ミリ秒で失敗にするタイマー役」。
- ※注意：これは待つのをやめるだけで、**通信は裏で続きます**（本当に止めるには AbortController が必要）。

## 9. 未経験向け 図解（Why → What → How）

文字だけでは掴みにくいしくみを、かんたんな図で見ます。各図に「なぜ・何を・どうやって」を添えました。※図はイメージ優先です。

### 図1：単一HTMLは「全部入りの1ファイル」

```
        ┌─────────────────────────────┐
        │      1つの .html ファイル      │
        │  ┌───────┐┌───────┐┌───────┐ │
        │  │ 見た目 ││ 動き  ││ 画像  │ │
        │  │ (CSS) ││ (JS)  ││(埋込) │ │
        │  └───────┘└───────┘└───────┘ │
        └─────────────────────────────┘
             ↓ ダブルクリック
        ┌─────────────┐
        │  ブラウザで動く │ ← ネット不要・インストール不要
        └─────────────┘
```

- **Why（なぜ）**：ファイルが分かれていると、渡す時に足りなくなったり、ネットが無いと動かなかったりします。1つにまとめると「渡せばすぐ動く」。
- **What（何を）**：見た目(CSS)・動き(JS)・画像まで、ぜんぶ1枚のHTMLに入れます。
- **How（どうやって）**：`<style>`にCSS、`<script>`にJS、画像は`data:`で文字に変えて埋め込む。AIに「単一HTMLで、外部読み込みなしで」と頼めばOK。

### 図2：保存のしくみ（state → save → load）

```
   あなたの操作            アプリの記憶            端末の保存箱
  （気分を変える）          state               localStorage
       │                 ┌──────┐               ┌────────┐
       └──── 変更 ──────▶ │ 状態  │ ── save() ──▶ │ 保存    │
                         └──────┘               └────────┘
                            ▲                        │
        起動時 ─── load() ───┴──────── 読み出し ───────┘
```

- **Why（なぜ）**：閉じると記憶が消えると、毎回やり直しになって不便だから。
- **What（何を）**：`state`（今の状態）を`save()`で保存箱へ、起動時に`load()`で戻す。
- **How（どうやって）**：文字に変換して`localStorage`へ保存。壊れていても初期値で動く（既定値マージ）ので、アプリは必ず起動します。

### 図3：AI相談の「3段フォールバック」

```
  あなたの相談
      │
      ▼
  ┌───────────────┐  キーあり   ┌──────────────┐
  │ ① 手動APIキー  │ ─────────▶ │ 外部AI(賢い)  │
  └───────┬───────┘            └──────────────┘
          │ キーなし
          ▼
  ┌───────────────┐  使える     ┌──────────────┐
  │ ② キー不要接続 │ ─────────▶ │ 外部AI(賢い)  │
  └───────┬───────┘            └──────────────┘
          │ 失敗
          ▼
  ┌───────────────┐            ┌──────────────┐
  │ ③ ローカル応答 │ ─────────▶ │ 黒猫先生(内蔵) │ ← 必ず返事する
  └───────────────┘            └──────────────┘
```

- **Why（なぜ）**：ネットや鍵が無い時に「無反応」だと、こわれたと思われるから。
- **What（何を）**：①手動キー → ②キー不要 → ③ローカル、の順で試します。
- **How（どうやって）**：`sendChat()`が上から順に判定し、外部が失敗しても`replyFor()`（内蔵の黒猫先生）に切り替え。だから**必ず返事**が来ます。

### 図4：時計が動くしくみ（1秒ループ）

```
  ┌──────────────────────────────┐
  │  1秒ごとにくり返す(setInterval) │
  │        │                     │
  │        ▼                     │
  │   いまの時刻を取る(new Date)    │ ← 毎回“今”を読み直すのがコツ
  │        │                     │
  │        ▼                     │
  │   画面に表示(09:05:07)         │
  └──────────────────────────────┘
```

- **Why（なぜ）**：数えた回数で時刻を出すと、裏タブなどでズレるから。
- **What（何を）**：1秒ごとに「いまの時刻」を取り直して表示。
- **How（どうやって）**：`setInterval(tick,1000)`で`tick()`を回し、中で毎回`new Date()`を読む。

### 図5：ファイル全体の地図（もう一度）

```
  .html ファイル（上から下へ）
  ┌────────────────────────────┐
  │ head   … 設定(文字コード/画面幅) │
  ├────────────────────────────┤
  │ style  … 見た目(色・配置)      │
  ├────────────────────────────┤
  │ body   … 画面(13枚のカード)    │
  ├────────────────────────────┤
  │ script … 動き(約95の関数)      │
  └────────────────────────────┘
```

- **Why（なぜ）**：どこに何があるか分かると、直したい場所にすぐ行けるから。
- **What（何を）**：HTMLは head → style → body → script の順で並ぶ。
- **How（どうやって）**：直したいのが「見た目」ならstyle、「動き」ならscript、「画面の部品」ならbody、と当たりをつける。
