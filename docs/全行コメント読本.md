# 付録：全行コメント入り ソースコード読本 ― フリガナつき・超初心者向け

コードは「外国語の説明書」に似ています。読めないのは、あなたの理解力の問題ではなく、**訳がついていないから**です。この付録では、実物のコードの**すべての行に日本語のコメントを直接書き込みました**。左に本物のコード、その行のうしろに「この行は何をしているか」が書いてあります。

- コードはすべて実物（黒猫先生の日めくり v2.0 PRO）と同じです。追加したのは `// ←` から後ろのコメントだけです。
- **`//` から後ろは、コンピュータには読まれません**（人間へのメモ）。だから、いくら書いても動作は変わりません。
- まずコメントだけを縦に読んでください。それだけで「何をしているアプリか」が分かります。

## はじめに覚える記号（3つだけ）

| 記号 | 読み方 | 意味 |
|---|---|---|
| `{ }` | 波かっこ | 「ここからここまでが一つのまとまり」 |
| `( )` | 丸かっこ | 「渡すもの」を入れる袋 |
| `;` | セミコロン | 「この行はここでおしまい」 |

## 1. アプリが覚えておくこと ― state（ステート＝状態）

```js
let state={                                          // ← 「state（状態）」という入れものを作る。letは中身を変えられる箱
  mode:"静寂",                                       // ← いまの気分モードは「静寂」。左が名前、右が中身
  params:Object.assign({},{kind:8,harsh:6,humor:7,calm:9,intel:9}),
                                                     // ← 人格の5つの数値。Object.assign（オブジェクト・アサイン）は「コピーして入れる」
                                                     //    優しさ8・毒舌6・ユーモア7・静けさ9・知性9
  slots:{},                                          // ← プリセットをしまう、からっぽの棚。{}は「空の入れもの」
  pts:0                                              // ← 応援ポイント。ゼロから始まる
};                                                   // ← 状態の定義おわり（;で1行の終わり）
```

**ひとこと**：アプリが覚えることを、この1か所に集めています。※イメージ：手帳の1ページに、今日の気分も持ち物も全部書いておく感じ。

## 2. 前回の続きから始める ― load（ロード＝読みこむ）

```js
function load(){                                     // ← 「load」という作業のまとまりを作る。functionは関数（かんすう）
  try{                                               // ← try（トライ）＝ためす。失敗するかもしれない処理を安全に囲む
    const raw=localStorage.getItem(STORE_KEY);       // ← 保存箱から、鍵(STORE_KEY)のデータを取り出して raw に入れる
    if(raw){                                         // ← if（イフ）＝もし。データがあった時だけ、次へ進む
      const o=JSON.parse(raw);                       // ← 文字列を元の形に戻す。JSON.parse（ジェイソン・パース）＝読み解く
      if(o.mode)state.mode=o.mode;                   // ← 保存に気分があれば、今の状態に入れる
      if(o.params)state.params=o.params;             // ← 人格の数値も、あれば入れる
      if(o.slots)state.slots=o.slots;                // ← プリセットの棚も、あれば入れる
      if(typeof o.pts==="number")state.pts=o.pts;    // ← ポイントは「数値なら」入れる。typeof（タイプ・オブ）＝種類を調べる
    }
  }catch(e){}                                        // ← catch（キャッチ）＝失敗を受け止める。何もしないので、アプリは止まらない
}
```

**ひとこと**：保存が壊れていても、`catch`が受け止めるのでアプリは必ず起動します。※イメージ：引き出しが空っぽでも、机はふつうに使える。

## 3. 続きを残す ― save（セーブ＝保存する）

```js
function save(){                                     // ← 「save」という作業のまとまりを作る
  try{                                               // ← 失敗しても大丈夫なように囲む
    const raw=localStorage.getItem(STORE_KEY);       // ← いまの保存内容を、いったん取り出す
    const o=raw?JSON.parse(raw):{};                  // ← あれば読み解き、無ければ空の箱を用意。「? :」は"〜なら前、違えば後"
    o.mode=state.mode;                               // ← いまの気分を、保存用の箱に写す
    o.params=state.params;                           // ← いまの人格の数値も写す
    o.slots=state.slots;                             // ← プリセットの棚も写す
    o.pts=state.pts;                                 // ← ポイントも写す
    localStorage.setItem(STORE_KEY,JSON.stringify(o)); 
                                                     // ← 箱を文字列に変えて保存。JSON.stringify（ジェイソン・ストリンギファイ）＝文字にする
  }catch(e){}                                        // ← 保存に失敗しても、アプリは止めない
}
```

**ひとこと**：`load`と`save`は対（つい）です。**しまう→出す**の往復で、「続きから使える」が実現します。

## 4. 時計を1秒ずつ進める ― tick（ティック＝時を刻む）

```js
function tick(){                                     // ← 「tick」という作業のまとまり。1秒ごとに呼ばれる
  const now=new Date();                              // ← いまこの瞬間の時刻を取る。new Date（ニュー・デイト）
  const h=now.getHours(),m=now.getMinutes(),s=now.getSeconds();
                                                     // ← そこから「時・分・秒」を取り出す
  const p2=n=>String(n).padStart(2,"0");             // ← 数字を2ケタに整える小さな道具（9→"09"）。=>（アロー）＝「を受け取って〜する」
  document.getElementById("clock").innerHTML=`${p2(h)}:${p2(m)}<span class="sec">:${p2(s)}</span>`;
                                                     // ← 画面の"clock"という場所に 09:05:07 の形で表示する
  document.getElementById("band").textContent=BANDS[h];
                                                     // ← 時間帯の名前（朝・昼など）を表示。BANDS[h]は「h番目の言葉」
}
```

**ひとこと**：大事なのは**毎回`new Date()`で"いま"を読み直す**こと。数えた回数で時刻を出すと、少しずつズレます。

## 5. 相談の内容を見分ける ― classify（クラシファイ＝仕分ける）

```js
function classify(text){                             // ← 入力された文 text を受け取る
  const t=(text||"").trim();                         // ← 前後の空白を取り除く。「||""」は"無ければ空っぽ"の保険
  for(const [i,re] of INTENTS){                      // ← for（フォー）＝くり返し。意図の一覧を上から順に見ていく
    if(re.test(t)) return i;                         // ← 当てはまったら、その意図の名前を返して終了。test＝当てはまるか調べる
  }
  return "smalltalk";                                // ← どれにも当てはまらなければ「雑談」とする
}
```

**ひとこと**：「相談かな？ 勉強かな？」を仕分ける入口です。※イメージ：受付で「ご用件は？」と聞いて、担当窓口に振り分ける係。

## 6. 危ない入力を安全にする ― escapeHtml（エスケープ・エイチティーエムエル）

```js
function escapeHtml(s){                              // ← 表示したい文字 s を受け取る
  return s.replace(/[&<>]/g,                         // ← 文の中の & < > を探す。replace（リプレイス）＝置きかえる
    c=>({"&":"&amp;","<":"&lt;",">":"&gt;"}[c]));    // ← 見つけた記号を、安全な書き方に置きかえて返す
}
```

**ひとこと**：これが無いと、入力に紛れ込んだ命令が実行されてしまうこと（XSS）があります。**画面に出す前に必ず通す安全確認**です。

## 7. 秘密の鍵を隠す ― mask（マスク＝覆いかくす）

```js
const mask=k=>k?("****"+String(k).slice(-4)):"(なし)";
// ← 鍵 k を受け取る小さな道具
//   k があれば → "****" と、後ろから4文字だけをつなげて返す（slice(-4)＝末尾4つ）
//   k が無ければ → "(なし)" と返す
```

**ひとこと**：`sk-abcd1234` は `****1234` になります。診断情報を人に送っても、鍵は漏れません。

## 8. 待ちすぎを防ぐ ― withTimeout（ウィズ・タイムアウト＝時間切れつき）

```js
function withTimeout(p,ms){                          // ← 処理 p と、待つ時間 ms（ミリ秒）を受け取る
  return Promise.race([                              // ← Promise.race（プロミス・レース）＝2つを競争させ、先に終わった方を採用
    p,                                               // ← 走者①：本来やりたい処理
    new Promise((_,rej)=>setTimeout(()=>rej(new Error("timeout "+ms+"ms")),ms))
                                                     // ← 走者②：ms 後に「時間切れ」と言う係。setTimeout＝時間差で実行
  ]);
}
```

**ひとこと**：遅い時は走者②が先にゴールして「時間切れ」に。ただし**待つのをやめるだけで、通信自体は裏で続きます**（本当に止めるにはAbortControllerが必要）。

## 9. 肉球をふみふみする ― doPaw（ドゥ・ポウ＝肉球する）

```js
function doPaw(){                                    // ← 肉球を押した時の処理
  ac(); SFX.puni();                                  // ← 音の準備をして、「ぷに」と効果音を鳴らす
  paw.classList.remove("hit");                       // ← アニメの印をいったん外す
  void paw.offsetWidth;                              // ← ブラウザに「今すぐ計算して」と促す（アニメを最初から再生する定番テク）
  paw.classList.add("hit");                          // ← 印を付け直す＝アニメがもう一度再生される
  const today=new Date().toDateString();             // ← 今日の日付を文字で取る
  if(today!==lbDay){lbDay=today;lbToday=0;}          // ← 日付が変わっていたら、今日の回数を0に戻す（!==は「同じでない」）
  lbToday++; lbTotal++;                              // ← 今日の回数と、合計回数を1ずつ増やす（++は「1足す」）
  $("lbToday").textContent=lbToday;                  // ← 画面の表示を更新（今日の回数）
  $("lbTotal").textContent=lbTotal;                  // ← 画面の表示を更新（合計）
  if(lbToday%10===0){                                // ← 10回ごとに。%（パーセント）は「割った余り」＝余り0なら10の倍数
    const w=PAWWORDS[Math.floor(Math.random()*PAWWORDS.length)];
                                                     // ← ご褒美の言葉を、候補からランダムに1つ選ぶ
    showLB(w+"（ふみふみ "+lbToday+"）");             // ← 画面にその言葉を出す
    window.speak&&window.speak(w);                   // ← 声が使えるなら読み上げる（&&は「使えるなら実行」の書き方）
    SFX.chime();                                     // ← ごほうびの音を鳴らす
  }
  persist();                                         // ← 回数を保存しておく

```

**ひとこと**：ただのボタンに見えて、「音・アニメ・記録・保存・ごほうび」が詰まっています。楽しさは、こうした細部の積み重ねです。

## 10. タイマーを動かす ― tStart（ティー・スタート）

```js
function tStart(){                                   // ← タイマー開始の処理
  if(tRun)return;                                    // ← すでに動いていたら、何もせず終了（二重起動の防止）
  ac();                                              // ← 音の準備
  tRun=true;                                         // ← 「動作中」の印を立てる
  $("tmrStart").textContent="再開";                  // ← ボタンの文字を「再開」に変える
  tHandle=setInterval(()=>{                          // ← setInterval（セット・インターバル）＝一定間隔でくり返す
    tLeft--;                                         // ← 残り秒を1つ減らす（--は「1引く」）
    if(tLeft<=0){ tPhaseEnd(); }                     // ← 0以下になったら、区切りの処理へ
    tDraw();                                         // ← 画面の残り時間を描き直す
  },1000);                                           // ← 1000ミリ秒＝1秒ごとに実行する
}
```

**ひとこと**：`setInterval`は「1秒ごとに、この作業をして」という指示です。止める時は保管した`tHandle`を使って解除します。

## コメントを読むコツ（超初心者向け）

1. **`//` の右だけを縦に読む**：それだけで処理の流れが分かります。
2. **分からない行は飛ばす**：全部を一度に理解しなくて大丈夫。
3. **1行だけAIに聞く**：下の文をコピーして貼るだけです。

```
この1行が何をしているか、記号の意味も含めて、
プログラミング未経験の私に分かるように、たとえ話つきで説明してください。

【ここに1行を貼る】
```

## 自分のコードにもコメントを書こう

コメントは、**未来の自分への手紙**です。3か月後の自分は、今日の自分が考えたことを忘れています。

```js
// 良いコメントの例：なぜそうしたかを書く
const p2=n=>String(n).padStart(2,"0");  // ← 9を"09"にして、時計の桁を揃えるため

// もったいないコメントの例：見れば分かることを書く
lbToday++;  // ← lbTodayを1増やす
```

**ポイント**：「何をしたか」より「**なぜそうしたか**」を書くと、後で役に立ちます。
