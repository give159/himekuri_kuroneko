# エラー文かんたん翻訳集 ― 非IT職のための「まず何をする？」

ツールを作っていると、英語のエラーが出て手が止まることがあります。でも大丈夫。エラーは「どこがおかしいか教えてくれる案内」です。この表で「日本語の意味」と「まずやること」を確認し、それでも直らなければ最後の魔法の一言をAIに送ってください。

- エラーは**画面の開発者ツール（F12）→ Console（コンソール）**の赤い文字で見られます。
- **エラー文は"そのまま"コピー**してAIに貼るのが、いちばん速い直し方です（自分で要約しない）。

---

## いちばん大事な心得（これだけで9割ラク）

1. 赤い文字を**1行目から**読む（原因はたいてい1行目）
2. 文の**最後にある行番号**（例：`:42`）が、あやしい場所
3. 分からなければ、**そのままAIに貼る**

---

## よく出るエラー 早見表

| 出る英語 | 日本語の意味 | まず何をする？ |
|---|---|---|
| **Uncaught SyntaxError** | 書き方のミス（かっこ・記号の閉じ忘れなど） | エラーの行番号を見て、その行の `(` `)` `{` `}` `"` の**閉じ忘れ**を確認 |
| **Unexpected token** | 予想外の記号がある | その位置に、**余計な記号**や全角の記号（，。「」）が混じっていないか確認 |
| **Unexpected end of input** | 途中で終わっている | どこかの `}` や `)` が**足りない**。貼り付け時に**末尾が切れていないか**確認 |
| **is not defined** | その名前が見つからない | 名前の**打ち間違い**、または貼り忘れ。`〇〇 is not defined` の〇〇を探す |
| **is not a function** | それは関数として使えない | 名前は合っているが使い方が違う。その行をAIに貼って確認 |
| **Cannot read properties of null** | 目当てのものが見つからない（空っぽ） | ボタンや欄の**IDの綴り違い**、または読み込み順の問題 |
| **Cannot read properties of undefined** | まだ値が入っていないものを使った | データが用意される**前に使っている**可能性。AIに順番を聞く |
| **Failed to fetch** | 通信に失敗した | インターネット接続、またはAPIキーを確認。オフラインなら**キー不要のローカルで動く**はず |
| **NetworkError / CORS** | 外部との通信がブロックされた | 外部AI接続の設定を確認。基本機能はオフラインで動くので、まず切り分け |
| **QuotaExceededError** | 保存領域がいっぱい | ブラウザの保存（localStorage）が上限。不要なデータを消す／保存量を減らす |
| **The operation is insecure** | 安全上の理由で保存できない | シークレット/プライベートモードや `file:` の制約。通常モードで開く |
| **Uncaught (in promise)** | 裏の処理で失敗した | 直後に続く文をそのままAIへ。多くは通信やタイムアウト関連 |
| **NotAllowedError（音・通知）** | ユーザー操作が必要 | 音や通知は、**一度クリック/タップしてから**でないと動かない仕様 |
| **Maximum call stack size exceeded** | 同じ処理が終わらず繰り返した | 無限ループの可能性。直前に変えた箇所をAIに貼って相談 |

## エラーが「出ない」のに動かない時

赤いエラーが無いのに変な時は、次を確認します。

- **保存したファイルの名前**が `.txt` になっていないか → 末尾を `.html` に
- コードを**全部**貼れているか（先頭 `<!DOCTYPE html>`、末尾 `</html>` まで）
- 全角スペースや全角記号が混じっていないか（`（）` や `　`）
- ブラウザを**再読み込み**（Ctrl+R / スマホは引っぱって更新）

## それでも直らない時の「魔法の一言」（コピペ）

### パターン1：エラーが出ている
```
初心者です。次のエラーの原因と直し方を、専門用語を使わずに教えてください。
まず結論を1行で、次に「私が今すぐやること」を1つだけ示してください。

【ここにエラー文をそのまま貼る】
```

### パターン2：エラーは無いが動かない
```
初心者です。エラーは出ていませんが、【やりたいこと】が【実際に起きていること】に
なってしまいます。原因になりそうな箇所を3つに絞って、確認する順番つきで教えてください。
```

### パターン3：何を聞けばいいか分からない
```
初心者です。今この状態で詰まっています：【状況を一言で】。
次に私がやるべきことを、1つだけ教えてください。
```

---

## 覚えておくと安心な3つ

1. **エラーは敵じゃない。** どこを直せばいいかの手がかりです。
2. **そのまま貼るのが最速。** きれいに要約しようとすると、大事な情報が消えます。
3. **1回で直らなくて普通。** 直す→確かめる、を数回くり返せば、必ず進みます。

*詰まっても大丈夫。エラーの数だけ、あなたは強くなります。*
*面白きこともなき世を面白く。*
