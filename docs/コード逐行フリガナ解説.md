# ソースコード 一行ずつコメント解説編 ― フリガナつき

このツール「黒猫先生の日めくり v2.0 PRO」の中身を、**実物のコードそのまま**、一行ずつ日本語で解説します。専門用語には読み仮名（フリガナ）をつけ、非エンジニアでも「何をしているか」が追えるようにしました。

- ここに載せるコードは、配布している実物ファイルと同じです（v2.0 PRO）。
- 記号（`{ } ( ) => ;`）にも意味があります。まず日本語コメントだけ追って、慣れたら記号を見てください。
- ※イメージの例え話は「正確ではないが、つかむため」の補助です。

読み方の早見：`function`（ファンクション＝関数）／`const`（コンスト＝変えない入れもの）／`let`（レット＝変えられる入れもの）／`return`（リターン＝結果を返す）／`try`（トライ＝ためす）／`catch`（キャッチ＝失敗を受け止める）。

## 1. アプリの「今の状態」をまとめる ― state

```js
let state={
  mode:"静寂",
  params:Object.assign({},{kind:8,harsh:6,humor:7,calm:9,intel:9}),
  slots:{},        // preset名 -> params 保存領域
  pts:0
};
```

一行ずつ：

- `let state={` … 「state（ステート＝状態）」という**変えられる入れもの**を作り、中に色々しまい始めます。※イメージ：アプリの「今の気分ノート」。
- `mode:"静寂",` … いまの気分モードは「静寂」。`mode`（モード）が名前、`"静寂"`が中身。
- `params:Object.assign({}, {kind:8, ...}),` … 人格の5つの数値（優しさ8・毒舌6・ユーモア7・静けさ9・知性9）。`Object.assign`（オブジェクト・アサイン）は「まるごとコピーして入れる」命令。元を壊さないためのコピーです。
- `slots:{},` … プリセット（保存した人格）をしまう**からっぽの棚**。`{}`は「空の入れもの」。
- `pts:0` … 応援ポイントは0から。`pts`（ポインツ）。
- `};` … 状態ノートの定義おわり。

**まとめ**：アプリが覚えておくことを、この1か所に集めています。集めておくと、保存も復元も一気にできます。

## 2. 保存したデータを読みこむ ― load()

```js
function load(){
  try{const raw=localStorage.getItem(STORE_KEY);if(raw){const o=JSON.parse(raw);
    if(o.mode)state.mode=o.mode; if(o.params)state.params=o.params;
    if(o.slots)state.slots=o.slots; if(typeof o.pts==="number")state.pts=o.pts;}}catch(e){}
}
```

一行ずつ：

- `function load(){` … 「load（ロード＝読みこむ）」という**作業のまとまり**を定義。
- `try{` … 「try（トライ＝ためす）」。失敗するかもしれない処理を、安全に囲みます。
- `const raw=localStorage.getItem(STORE_KEY);` … 保存箱（localStorage）から、鍵`STORE_KEY`のデータを取り出して`raw`（ロウ＝生の文字列）に入れる。
- `if(raw){` … もしデータがあれば。`if`（イフ＝もし〜なら）。
- `const o=JSON.parse(raw);` … 文字列を、元のデータの形に戻す。`JSON.parse`（ジェイソン・パース＝文字列を解釈して戻す）。
- `if(o.mode)state.mode=o.mode;` … 保存に気分があれば、それを今の状態に反映。以下、人格・棚・ポイントも同様に、**あるものだけ**戻します。
- `}}catch(e){}` … `catch`（キャッチ）。もし途中で失敗しても、**何もせず通過**（＝アプリは止まらない）。

**まとめ**：データが壊れていても、`try-catch`で受け止めて初期状態で動きます。「絶対に起動する」を守る仕組みです。※イメージ：引き出しが空でも、机はちゃんと使える。

## 3. 状態を保存する ― save()

```js
function save(){
  try{const raw=localStorage.getItem(STORE_KEY);const o=raw?JSON.parse(raw):{};
    o.mode=state.mode;o.params=state.params;o.slots=state.slots;o.pts=state.pts;
    localStorage.setItem(STORE_KEY,JSON.stringify(o));}catch(e){}
}
```

一行ずつ：

- `function save(){ try{` … 「save（セーブ＝保存する）」を定義し、安全に囲む。
- `const o=raw?JSON.parse(raw):{};` … すでに保存があれば読み、無ければ空箱`{}`を用意。`? :`は「〜なら前、違えば後」という三択の書き方。
- `o.mode=state.mode; ...` … 今の気分・人格・棚・ポイントを、保存用の箱に写す。
- `localStorage.setItem(STORE_KEY,JSON.stringify(o));` … 箱を文字列に変えて（`JSON.stringify`＝ジェイソン・ストリンギファイ）、鍵`STORE_KEY`で保存箱へしまう。
- `}catch(e){}` … 失敗しても止まらない。

**まとめ**：変更のたびにこれを呼べば、次に開いた時も続きから使えます。

## 4. 1秒ごとに時計を動かす ― tick()

```js
function tick(){
  const now=new Date();
  const h=now.getHours(),m=now.getMinutes(),s=now.getSeconds();
  const p2=n=>String(n).padStart(2,"0");
  document.getElementById("clock").innerHTML=`${p2(h)}:${p2(m)}<span class="sec">:${p2(s)}</span>`;
}
```

一行ずつ：

- `function tick(){` … 「tick（ティック＝時を刻む）」を定義。
- `const now=new Date();` … **いまこの瞬間**の時刻を取得。`new Date()`（ニュー・デイト）。毎回これを呼ぶのがズレない秘訣です。
- `const h=..., m=..., s=...;` … 時・分・秒を取り出す。`getHours/Minutes/Seconds`（ゲット・アワーズ／ミニッツ／セカンズ）。
- `const p2=n=>String(n).padStart(2,"0");` … 数字を2ケタに整える小さな関数（例：9→"09"）。`padStart`（パッド・スタート＝前を埋める）。
- `document.getElementById("clock").innerHTML=...` … 画面の`clock`という場所に、`09:05:07`のように表示。`getElementById`（ゲット・エレメント・バイ・アイディー＝IDで画面の部品を探す）。

**まとめ**：この関数を1秒ごとに呼ぶことで時計が進みます。ポイントは「毎回いまの時刻を読み直す」こと。

## 5. 危ない入力を安全にする ― escapeHtml()

```js
function escapeHtml(s){return s.replace(/[&<>]/g,c=>({"&":"&amp;","<":"&lt;",">":"&gt;"}[c]));}
```

一行ずつ：

- `function escapeHtml(s){` … 受け取った文字`s`を安全にする関数。
- `return s.replace(/[&<>]/g, c=> ... )` … 文の中の `&` `<` `>` を、無害な表記に**置きかえて返す**。`replace`（リプレイス＝置きかえる）。
- `{"&":"&amp;","<":"&lt;",">":"&gt;"}[c]` … 見つけた記号を、対応する安全な文字に変換する対応表。

**まとめ**：これが無いと、入力に紛れた命令で画面が乗っ取られること（XSS＝クロス・サイト・スクリプティング）があります。表示の前に必ず通す「安全確認」です。※イメージ：外から来た荷物の中身チェック。

## 6. 秘密の鍵を伏せ字にする ― mask

```js
const mask=k=>k?("****"+String(k).slice(-4)):"(なし)";
```

一行ずつ：

- `const mask=k=>` … 鍵`k`を受け取る小さな関数。`=>`（アロー＝「を受け取って〜する」）。
- `k?( ... ):"(なし)"` … 鍵があれば前、無ければ「(なし)」。
- `"****"+String(k).slice(-4)` … `****`＋**末尾4文字だけ**をつなげる。`slice(-4)`（スライス＝後ろから4つ取る）。

**まとめ**：診断ログにAPIキーを載せても、`****abcd`のように末尾しか出ないので安全に共有できます。

## 7. 待ちすぎを防ぐ ― withTimeout()

```js
function withTimeout(p,ms){ return Promise.race([p, new Promise((_,rej)=>setTimeout(()=>rej(new Error("timeout "+ms+"ms")),ms))]); }
```

一行ずつ：

- `function withTimeout(p,ms){` … 処理`p`と、待ち時間`ms`（ミリ秒）を受け取る。
- `Promise.race([p, ... ])` … `Promise.race`（プロミス・レース）。**2つを競争させ、先に終わった方を採用**します。
- `new Promise((_,rej)=>setTimeout(()=>rej(...),ms))` … 「`ms`ミリ秒たったら失敗にする」タイマー役。`setTimeout`（セット・タイムアウト＝時間差で実行）。

**まとめ**：本来の処理が遅い時、タイマーが先にゴールして「時間切れ」にします。※注意：これは「待つのをやめる」だけで、**通信そのものは裏で続きます**（本当に止めるには AbortController が必要）。
