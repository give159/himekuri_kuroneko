# 非IT職のための「つくりたい」を形にするシート集

このファイルは、プログラミングの知識がなくても、AIと一緒に自分のツールを作れるように用意した**穴埋め式のワークシート**です。上から順に【　】を埋めていくだけで、「要件定義 → 設計 → 実装依頼」まで進みます。埋めた内容をそのままAI（ChatGPTやClaude）に貼れば、動くものが返ってきます。

- 難しい言葉は使いません。困ったら各シート末の「まるごとAIに聞く例文」をコピペしてください。
- 正解はありません。まず1周、ざっくり埋めるのが上手なコツです。

---

## この資料の使い方（3ステップ）

1. **シート1** で「何を作りたいか」を言葉にする（要件定義）
2. **シート2** で「どんな画面・動きにするか」を決める（設計）
3. **シート3** で「AIへの作成依頼文」に変換する（実装仕様）

各シートは10分で埋められます。埋め終わったら、シート3の依頼文をAIに送るだけです。

> ねらい：作る前に「これは何のためのものか」をはっきりさせます。ここが決まると、後がぶれません。

- 機能A：【　　　　　　　　　】

## 1-6. 使う場所・道具

# シート3：実装仕様シート（AIへの「作って」の伝え方）

> ねらい：シート1・2の内容を、AIがそのまま作れる「依頼文」に変えます。下の型の【　】を埋めるだけです。

## 3-1. 作成依頼テンプレ（これをAIに送る）
```
あなたは、初心者にやさしいWeb開発の先生です。
次の条件で「1つのHTMLファイルだけで動くツール」を作ってください。

■ 目的
【シート1-1 ひとことで言うと】

■ 使う人
【シート1-2 だれが使う】

■ ほしい機能（この3つだけでOK）
1. 【機能A】
2. 【機能B】
3. 【機能C】

■ 画面の並び
上から：【シート2-1 の1・2・3】

■ ボタンと動き
【シート2-2 の表の内容】

■ 覚えておく情報
【シート2-3】（なければ「保存は不要」）

■ 見た目
色・雰囲気：【シート2-4】／言葉づかい：【シート2-5】

■ 技術の約束（そのままコピーしてください）
・style と script を1つのHTMLにまとめる（外部読み込みなし・オフラインで動く）
・保存は localStorage を使い、壊れていても初期状態で動くようにする
・画面に文字を出すときは必ずエスケープして安全にする
・スマホの縦画面でも崩れないようにする

■ 出力してほしいもの
・完成したHTMLの全文
・使い方の3行説明
・あとで直したくなりそうな箇所のメモ
```

## 3-2. 直したい時の言い方（コピペ集）
- 「ここをこう変えて → 【変えたい所】を【こうしたい】。**既存は壊さず、変更点だけ**教えて。」
- 「エラーが出た → 『【エラー文をそのまま貼る】』。原因と直し方を、初心者向けに。まず結論から。」
- 「スマホで見づらい → ボタンをもっと大きく、押しやすくして。」

## 3-3. 完成の確認（3つだけ）
- □ スマホで開いて、ちゃんと表示される
- □ ほしかった機能3つが動く
- □ 閉じて開き直しても、覚えていてほしい情報が残っている（保存が必要な場合）

# 全力サポート資料（つまずいた時に開くページ）

## Q. AIの返事のコードを、どこに貼れば動くの？
1. パソコンのメモ帳（Windows）や テキストエディット（Mac）を開く
2. AIがくれたHTMLを**全部**貼り付ける
3. ファイル名を `mytool.html`（末尾を .html に）で保存
4. そのファイルをダブルクリック → ブラウザで開けば動きます

## Q. うまく動かない時の3ステップ
1. **エラー文をそのままコピー**して、AIに「これ直して」と貼る（自分で要約しない）
2. 直った理由も一緒に聞く（次に活きる）
3. それでもダメなら、機能を1つに減らして「まず動く形」に戻す

## Q. 専門用語がこわい
- **HTML**：ブラウザで開くと画面になるファイル。この1枚があれば動きます。
- **localStorage**：ブラウザの中の小さな保存箱。閉じても覚えてくれます。
- **エスケープ**：入力された文字を安全に表示する仕組み。AIに任せてOK。
- 分からない言葉は、AIに「【言葉】を小学生にも分かるように説明して」と聞けば大丈夫。

## つまずきを防ぐ3つの心得
1. 一度に完成させようとしない。**1機能ずつ**足す。
2. うまくいったら、その時点のファイルを**別名で保存**（戻れる安心）。
3. 詰まったら**一晩寝る**。朝の自分は、少し賢いです。

## 困った時の頼り方（AIへの魔法の一言）
```
私は初心者で、今ここで詰まっています：【状況】。
専門用語を使わず、次に私がやるべきことを1つだけ教えてください。
```
