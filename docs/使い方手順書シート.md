# 自作ツールの「手順書・使い方」かんたん作成シート

自分で作ったツールを、人に渡す（または自分用に残す）ための**手順書を、穴埋めで書けるシート**です。ゼロから書くと悩みますが、【　】を上から埋めるだけなら10分で仕上がります。専門用語は使いません。

- 全部埋める必要はありません。当てはまる所だけでOK。
- 迷ったら各所の「記入例」をまねしてください。
- 書き終えたら、この見出しごと配布ファイル（README）や本文にコピーできます。

---

## 使い方（3ステップ）
1. **A. 表紙シート** … このツールが「何か」を1行で
2. **B. 使い方シート** … 開き方と基本の手順
3. **C. こまった時シート** … Q&Aと連絡先

埋め終わったら、A→B→Cの順につなげれば、そのまま手順書になります。

---

# A. 表紙シート（このツールは何？）

```
■ ツールの名前
【　　　　　　　　　】
（例：うさうさ朝じたくタイマー）

■ ひとことで言うと
このツールは【　　　　　　　　　　　　　】ためのものです。
（例：朝の準備を、声のカウントダウンで応援する）

■ こんな人におすすめ
【　　　　　　　　　】な人
（例：朝、時間の感覚がなくなりがちな人）

■ 用意するもの
・機械：□スマホ　□パソコン
・インターネット：□不要　□必要
・かかる時間：はじめて使う人で約【　　】分
```

**記入例**
```
名前：うさうさ朝じたくタイマー
ひとこと：朝の準備を声のカウントダウンで応援するためのものです。
おすすめ：朝、時間の感覚がなくなりがちな人
用意：スマホ／インターネット不要／約3分
```

# B. 使い方シート（手順）

## B-1. はじめる（開き方）
```
1. 【　　　　　　　　】を開きます。
   （例：送られてきた mytool.html をタップ）
2. 画面が出たら、最初に一度【　　　　　】します。
   （例：画面のどこかを1回タップ／音を使う場合に必要）
```

## B-2. 基本の使い方（3ステップで）
```
STEP1：【　　　　　　　　　】
   → こうなります：【　　　　　　　】
STEP2：【　　　　　　　　　】
   → こうなります：【　　　　　　　】
STEP3：【　　　　　　　　　】
   → こうなります：【　　　　　　　】
```
（例）
```
STEP1：準備にかける時間を選ぶ → タイマーがセットされます
STEP2：スタートを押す → 声でカウントダウンが始まります
STEP3：終わると通知 → 「いってらっしゃい」と声が鳴ります
```

## B-3. べんりな使い方（あれば）
```
・【　　　　　　　】すると、【　　　　　　　】できます。
・【　　　　　　　】は、次に開いた時も覚えています。
```

## B-4. やめる・閉じる
```
・終わるときは【　　　　　　　】。
・データは【消えません／この端末に残ります】。
```

# C. こまった時シート（Q&A・連絡先）

## C-1. よくある質問（当てはまるものを埋める）
```
Q. 音が出ません
A. 【　　　　　　　　　　　】をお試しください。
   （記入例：画面を一度タップしてから、端末の音量を上げてください）

Q. 入力した内容が消えました
A. 【　　　　　　　　　　　】。
   （記入例：シークレットモードでは閉じると消えます。通常モードでお使いください）

Q. うまく動きません
A. 【　　　　　　　　　　　】。
   （記入例：ページを一度読み込み直してください。直らない場合はご連絡ください）
```

## C-2. 使うときのお願い・注意
```
・【　　　　　　　　　】でお使いください。
   （記入例：入力した内容はこの端末の中にだけ保存されます）
・【　　　　　　　　　】はご遠慮ください。
   （記入例：大事なパスワードなどの入力）
```

## C-3. 連絡先
```
うまくいかない時・ご質問は【　　　　　　　　　】まで。
（記入例：作った人のメール／SNS／フォームのURL）
作成：【あなたの名前・屋号】／版：【v1.0】／日付：【　　年　月　日】
```

# 全力サポート資料（書く手が止まった時に開く）

## 1. 時短のコツ「3つだけ埋める」
全部埋めようとすると止まります。まずこの3つだけ埋めれば、手順書は成立します。
1. **名前**（A：ツールの名前）
2. **基本の3ステップ**（B-2）
3. **連絡先**（C-3）
残りは後から足せます。

## 2. 「動きの説明」が書けない時
自分の画面を見ながら、実際に1回操作して、
「押した」→「こうなった」を**そのまま声に出して**、それを書くだけでOKです。
きれいな文章にしなくて大丈夫。「スタートを押す→声が鳴る」で十分伝わります。

## 3. まるごとAIに清書してもらう（コピペ用）
穴埋めした内容を、次の文といっしょにAIへ貼ると、読みやすい手順書に整えてくれます。
```
次のメモを、非エンジニアのお客様向けの「使い方手順書」に整えてください。
専門用語は言い換え、やさしく、短くしてください。見出しは「使い方」「困った時」に分けて。

【ここに、A・B・Cで埋めた内容を貼る】
```

## 4. 渡す前の最終チェック（3つ）
- □ はじめて見る人が、**開き方**でつまずかないか
- □ **基本の3ステップ**だけで、最低限の目的を達成できるか
- □ **連絡先**が書いてあるか（困った人が戻ってこられる）

## 5. よくある不安への答え
- 「文章が下手かも」→ 手順書は上手さより**正確さと短さ**。箇条書きで勝ちです。
- 「情報が足りないかも」→ 足りなければ、使った人が質問してくれます。連絡先があれば大丈夫。
- 「一度で完璧にしたい」→ **v1.0で出して、質問がきたら追記**が正解。完璧は後から。

---

## 保存とリポジトリへの入れ方
- このシートで作った手順書は、配布ファイルの `README` や、ツールと同じフォルダに `使い方.md` として置くと親切です。
- 迷ったら、埋めた A・B・C をそのまま README に貼れば、それが立派な手順書になります。

*完璧を目指すより、まず1枚。あなたのツールに、やさしい道案内を。*
*面白きこともなき世を面白く。*
