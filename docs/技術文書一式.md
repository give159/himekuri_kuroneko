# 第1部　要件定義書

## 1. 目的
学習・作業のお供として、時計・励まし・集中支援・AI相談を1つにまとめた「毎日開きたくなる」個人用ツールを提供する。

## 2. 利用者
- 主利用者：学習中の個人（文系・非エンジニアを含む）
- 副利用者：本書（Kindle）の読者（教材サンプルとして）

## 3. 動作環境
- 一般的なモダンブラウザ（PC／スマートフォン）
- ネットワーク：不要（AI外部接続のみ任意でオンライン）
- インストール：不要（HTMLファイルを開くだけ）

## 4. 機能要件（FR）
| ID | 機能 | 概要 |
|---|---|---|
| FR-01 | 日めくり表示 | 日付・時計・挨拶・今日の一言を表示（1秒更新） |
| FR-02 | 推し台詞 | 時間帯と気分（静寂・甘々・毒舌・遊び心など）に応じた一言 |
| FR-03 | AI相談 | テキストで相談。声（読み上げ）つき応答 |
| FR-04 | 人格パラメータ | 優しさ・毒舌・ユーモア等5軸の調整と保存（プリセット） |
| FR-05 | 集中スイッチ | 肉球ふみふみ・しっぽ撫でで気分転換（なつき度が変化） |
| FR-06 | 推しボイス設定 | 声の種類・低さ・速さ・高さの調整と試聴 |
| FR-07 | 集中タイマー | ポモドーロ／深集中／カスタム。成果の記録 |
| FR-08 | アラーム | 時刻指定で声とベルで通知（二重発火防止つき） |
| FR-09 | 推しボイス・ドラマ | 5分×3本の朗読。テキストで話しかけると声で返事 |
| FR-10 | English Study | 定番フレーズの表示・発音のコツ・端末英語音声での読み上げ |
| FR-11 | BGM・効果音 | カフェBGM・ベル・効果音をその場で合成（音源ファイル不要） |
| FR-12 | 設定・診断 | APIキー設定（任意）、デバッグ虫による診断ログのコピー |

## 5. 非機能要件（NFR）
| ID | 区分 | 要件 |
|---|---|---|
| NFR-01 | 配布 | 単一HTMLファイル。外部読み込みなし・完全オフラインで全基本機能が動作 |
| NFR-02 | 保存 | localStorage による端末内保存。壊れていても既定値で必ず起動 |
| NFR-03 | セキュリティ | 画面出力は全てエスケープ（XSS対策）。APIキーは端末内にのみ保持し、診断ログでは伏せ字化 |
| NFR-04 | 可用性 | AI外部接続の失敗時はローカル応答へ自動フォールバック（無応答にしない） |
| NFR-05 | 応答性 | 外部接続にはタイムアウトを設け、一定時間で打ち切る |
| NFR-06 | 品質 | 版更新時は商用QA（単体・結合・総合・モンキー）合格を条件にPRO刻印 |

## 6. AI接続の要件
- 既定は**ローカル応答**（キー不要・オフライン）。
- 手動でAPIキーを設定した場合のみ外部API（Anthropic）に接続。
- アーティファクト環境ではキー不要接続が可能（実行環境が認証を付与）。
- 優先順位：手動キー ＞ キー不要 ＞ ローカル。いずれも失敗時はローカルで必ず応答。

# 第2部　詳細設計書

## 1. アーキテクチャ
単一HTML内に「状態（state）→描画（render）→操作（イベント）」の循環を持つ、カード積み上げ型のSPA構成。

```
[ユーザー操作] → イベントハンドラ → state更新 → save() → 画面更新
                                   ↑
起動時: load() が localStorage から state を復元（失敗時は既定値）
```

## 2. 状態設計（実物スキーマ）
```js
let state = {
  mode: "静寂",                       // 現在の気分モード
  params: {kind:8, harsh:6, humor:7, calm:9, intel:9},  // 人格5軸
  slots: {},                          // プリセット名 -> params の保存領域
  pts: 0                              // ポイント（応援ポイント）
};
```
- 保存キー：`STORE_KEY`（localStorage）
- `load()`：try-catch で読み込み、項目ごとに存在確認して既定値へマージ
- `save()`：変更のたびに JSON.stringify で書き戻し

## 3. 主要モジュールと実関数
| 領域 | 実関数 | 役割 |
|---|---|---|
| 状態 | `load()` / `save()` | 復元・保存（NFR-02） |
| 時計 | `tick()` | 1秒ループ。毎回 `new Date()` で現在時刻を読み直す |
| 応答 | `classify()` → `replyFor()` | 入力文を正規表現で意図分類し、ローカル応答を生成 |
| AI | `sendChat()` → `apiReply()` / `artifactReply()` | 3段フォールバックの入口と各経路 |
| 保護 | `withTimeout(p, ms)` | `Promise.race` による時間切れ（通信自体は中断しない） |
| 秘匿 | `mask(key)` | `****` ＋末尾4桁のみ表示 |
| 音声 | `speak(text)` | `SpeechSynthesisUtterance` による読み上げ |
| 英語 | `showPhrase()` / `enSpeak()` | フレーズ表示・お手本読み上げ（データは `EN`：カテゴリ別 {en, ja, tip}） |
| 音 | `getAC()` ほか | AudioContext の取得と、ユーザー操作内での `resume()` |
| 集中 | `doPaw()` / `updateAff()` / `spawnHearts()` | 肉球・なつき度・演出 |
| 診断 | `buildLog()` / `copyLog()` | 診断ログ生成（`version : v2.0 PRO` を含む）とコピー |

## 4. AI相談の処理フロー
```
sendChat(text)
  ├ 手動キーあり → apiReply()  … fetch + x-api-key（直叩きヘッダ対応）
  ├ キーなし     → artifactReply() … キー不要経路（model: claude-sonnet-4-6）
  │                 失敗したら __keylessDead を立て、以後この経路を再試行しない
  └ いずれも失敗 → replyFor() … ローカル黒猫先生（無応答にしない）
すべての外部呼び出しは withTimeout() で時間切れを設ける
```

## 5. 音（WebAudio）の設計
- 音源ファイルを持たず、オシレータ＋ゲインでその場で合成。
- `AudioContext` はユーザー操作の中で生成・`resume()`（自動再生制限への対応）。
- カフェBGM：マスターゲイン 0.28、ローパス 2200Hz。初回タップで解錠。

## 6. セキュリティ設計
- 画面出力は `escapeHtml` を通す（`<img onerror>` 等を無効化することをQAで確認済み）。
- APIキーは localStorage（端末内）のみ。配布ファイルへの埋め込みは行わない。
- 診断ログのキーは `mask()` で伏せ字。

## 7. 版管理
- 版表記は3箇所（フッターバッジ／`buildLog` の `version :` 行／冒頭CHANGELOG）を一致させる。
- 現行：v2.0 PRO（商用QA 22項目合格で刻印。QAレポートID 260710）。

# 第3部　修正・拡張ガイド（新機能の作り方）

## 1. 拡張の基本方針
1. **壊さずに足す**：既存カードの中身は触らず、新しいカードを追加する。
2. **1機能＝1カード**：HTMLのカード（`card`）単位で見た目とロジックを完結させる。
3. **状態は state に集約**：新機能の保存項目は `state` にフィールドを追加し、`load()` の既定値マージにも1行足す。

## 2. 新しいカードを足す手順（例：メモカード）
1. 既存カードのHTMLブロックをコピーし、`card-t`（見出し）とIDを新名に変える。
2. `<script>` 内に初期化関数を1つ作り、既存の初期化列の末尾で呼ぶ。
3. 保存が必要なら `state` にフィールドを追加：
```js
// stateへ追加（既定値）
state.memo = state.memo || "";
// 変更時
$("memoIn").addEventListener("input", e => { state.memo = e.target.value; save(); });
```
4. 画面出力は必ずエスケープを通す（`innerHTML` に生の文字列を入れない）。

## 3. AI応答に新しい話題を足す
- ローカル応答は `classify()` の正規表現に分岐を1つ追加 → `replyFor()` に応答文を追加。
- 外部AIの口調は、`apiReply()` / `artifactReply()` が組み立てるシステム文を編集する。

## 4. 版を上げるとき（リリース手順）
1. 変更を実装 → `node --check` で全scriptの構文確認。
2. jsdomヘッドレスで商用QA（起動0エラー／XSS／AI3経路／タイマー／BGM／localStorage）。
3. 合格したら版表記3箇所を更新し、CHANGELOGに1行追記。
4. 配布ファイル名にも版を含める（例：`_v2_1.html`）。

## 5. やってはいけないこと
- APIキーをソースに書き込む（配布で漏えいする）。
- `SpeechRecognition`（音声入力）の再導入を無計画に行う（v1.9で意図的に削除済み。file:配布では動作しない）。
- 版表記の一部だけ更新する（表示とログの不一致は信頼を損なう）。

# 第4部　お客様向け 利用手順書

## 1. はじめに
このツールは、開くだけで使える「学習と集中のお供」です。インストールも会員登録も不要で、通信も基本的に使いません。

## 2. 使いはじめる
1. お渡ししたHTMLファイルをダブルクリック（スマートフォンではブラウザで開く）。
2. 画面が表示されたら、そのまま使えます。初回に一度どこかをタップすると音が有効になります。

## 3. 画面のみかた（主なカード）
| カード | できること |
|---|---|
| ただいまの刻 | 日付・時計・今日のひとこと |
| この時間の、推し台詞 | 時間帯に合わせた黒猫先生の一言。気分ボタンで口調が変わります |
| 黒猫先生に相談 | 悩みや質問を入力して送信。先生が声つきで答えます |
| 集中タイマー | ポモドーロなどの集中時間を計ります |
| 集中スイッチ | 肉球をふみふみすると気分転換。なつき度が上がります |
| English Study | 英語フレーズとお手本の発音を聞けます |

## 4. よくある質問
**Q. 音が出ません**
A. 画面を一度クリック（タップ）してください。それでも出ない場合は、端末の音量とブラウザのタブのミュートをご確認ください。

**Q. 入力した内容や設定が消えました**
A. プライベートブラウズ（シークレットモード）では、閉じると消える仕様です。通常モードでお使いください。

**Q. AIの返事が同じような内容ばかりです**
A. 標準では通信を使わない「ローカル応答」で動いています。設定画面でAPIキーを入れると、外部のAIに接続できます（任意・通信が発生します）。

**Q. 動きがおかしくなりました**
A. ページを再読み込みしてください。直らない場合は、ブラウザの設定からこのページのサイトデータ（localStorage）を削除すると初期状態に戻ります（保存した設定は消えます）。

## 5. 安心してお使いいただくために
- 入力内容は端末の中にだけ保存されます（標準では外部送信しません）。
- APIキーを設定した場合のみ、相談文が外部のAIサービスへ送られます。
- 不具合の際は、画面右下の「デバッグ虫」から診断情報をコピーしてご連絡ください（APIキーは自動で伏せ字になります）。

## 6. お問い合わせ
配布元（うさうさ研修工房）までご連絡ください。連絡先はお渡し時の案内をご覧ください。
