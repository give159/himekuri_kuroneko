# アーティファクト版の使い方 ― リンクを開くだけ

このツールには、2つの使い方があります。

- **GitHub版**：ファイルを保存して開く（オフラインでも動く。手元に残したい方へ）
- **アーティファクト版**：**リンクを開くだけ**で、その場ですぐ使える（まず触ってみたい方へ）

このページは「アーティファクト版」の使い方です。

---

## 1. アーティファクト版とは

- ダウンロード不要。**URLを開くと、すぐにツールが動きます**。
- スマホでもパソコンでも、ブラウザがあればOK。
- 「まず試してみたい」「保存は後でいい」という方に向いています。

## 2. 使いはじめる（3ステップ）

1. 本のQRコード（②アーティファクト版）を読み取る、または配布URLを開く
2. 画面が表示されたら、そのまま使えます
3. 音を使う時は、最初に一度どこかを**タップ／クリック**してください

## 3. GitHub版との違い（どちらを選ぶ？）

| | アーティファクト版 | GitHub版 |
|---|---|---|
| 始め方 | リンクを開くだけ | ファイルを保存して開く |
| オフライン | 開いた後は基本動くが、再訪にはネット接続が必要な場合あり | 一度保存すれば完全オフライン |
| 保存(設定) | ブラウザに保存（同じ端末・同じブラウザで継続） | 同左 |
| おすすめ | まず試したい／手軽に開きたい | じっくり使う／手元に残したい |

> 迷ったら、**まずアーティファクト版で試して**、気に入ったらGitHub版を保存、が簡単です。

## 4. 注意点（正直に）

- アーティファクト版のリンクは、公開状況によって変わることがあります。**最新のURLは特典リポジトリでご確認**ください。
- 会員登録や課金は不要です（もし要求する画面が出たら、それは別物です。開かないでください）。
- 入力内容はブラウザの中に保存され、標準では外部に送信されません。AI相談でAPIキーを設定した時だけ、外部AIと通信します（任意）。

## 5. うまく開けない時

- リンクをタップしても開かない → ブラウザ（Safari/Chrome）で開き直す
- 画面が真っ白 → 一度ページを再読み込み
- 音が出ない → 画面を一度タップ／端末の音量・タブのミュートを確認

## 6. 困った時の「魔法の一言」（コピペでAIに聞く）
```
配布されたツールのリンクを開いたのですが、【今の状況：開かない／真っ白／音が出ない など】です。
初心者向けに、次にやることを1つだけ教えてください。
```

*まずは開いて、触ってみてください。それがいちばんの近道です。*
*面白きこともなき世を面白く。*
