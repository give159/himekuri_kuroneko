# うさうさ読書手帖 ― 読書週間 応援ジェネレーター（PRO）

読書の時間を、もっと楽しく。うさうさ研修工房の「読書手帖」ジェネレーターです。
朝の一行を受け取り、読んだ本を手帖に綴じ、今週の読書を桜で見守る——そんな小さな相棒です。
インストール不要・オフラインで動きます。

## 使い方（2通り）

### ① ダウンロードして使う（PRO版・手元に残る）
- ファイル：`うさうさ読書手帖_読書週間応援ジェネレーター_PRO.html`
- 開き方：ダウンロードして**ダブルクリック**（スマホはブラウザで開く）
- 一度保存すれば、ネットがなくても使えます。

### ② リンク／QRで開く（すぐ試す・アーティファクト版）
- リンク：https://claude.ai/public/artifacts/65ea8cd5-236c-4d3b-a81f-72e03babddde
- QR：同フォルダの `QR_読書手帖応援ジェネレーター.png` をスマホのカメラで読み取り。

## できること（かんたん説明）
- **今日の頁をひらく**：朝いちばんに、今日の一行を受け取れます。
- **学びの手帖に綴じる**：読んだ本やひとことを記録。手帖がたまっていきます。
- **今週の読書週間（桜）**：今週の読書を桜で見守ります。続けるほど咲きます。
- **和菓子のごほうび**：朝の頁・今日の読書・手帖を綴じるたびに、和菓子がひとつ並びます。

## こまった時
- 音や動きがおかしい → ページを再読み込み。
- 記録が消えた → シークレット/プライベートモードでは閉じると消えます。通常モードで。
- 入力内容は**お使いの端末（ブラウザ）の中だけ**に保存され、他の端末・他の方には共有されません。
